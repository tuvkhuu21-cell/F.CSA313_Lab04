## 2. Төслийн хэрэгжүүлэлт

`GradeCalculator` класс нь оюутны оноог тооцоолох хоёр үндсэн методтой.

- `letterGrade(double score)` — 0–100 оноонд үндэслэн A, B, C, D, F үсгэн үнэлгээ тодорхойлно.
- `totalScore(double att, double lab, double quiz1, double quiz2, double exam)` — ирц, лаборатори, сорил болон шалгалтын оноог нэгтгэнэ.

Онооны зөвшөөрөгдөх хязгаарыг зөрчсөн тохиолдолд `IllegalArgumentException` үүсгэнэ.

## 4. Туршилтын үр дүн

### Зөв хэрэгжүүлэлтийн тест

```text
Tests run: 27, Failures: 0, Errors: 0, Skipped: 0
BUILD SUCCESS
```

Бүх 27 тест амжилттай ажилласан.

**Нотолгоо:** `results/mvn-test.txt`

### Мутацийн туршилт

`GradeCalculator.java` файлын дараах нөхцөлийг зориуд өөрчилсөн.

Анхны нөхцөл:

```java
if (score >= 90) return "A";
```

Мутацийн нөхцөл:

```java
if (score > 90) return "A";
```

Мутацийн үр дүн:

```text
Tests run: 27, Failures: 2, Errors: 0, Skipped: 0
BUILD FAILURE
```

Амжилтгүй болсон тестүүд:

1. `ninetyIsExactlyA`
2. `letterGradeBoundaries` — 90 онооны тохиолдол

Хоёр тестэд хүлээгдсэн үнэлгээ `A` байсан боловч бодит үр дүн `B` болсон.

**Нотолгоо:** `results/mvn-test-mutant.txt`

Мутацийн дараа эх кодыг зөв нөхцөлд сэргээж, 27 тестийг дахин амжилттай ажиллуулсан.

## 5. Дүгнэлт

Энэхүү лабораторийн ажлаар JUnit 5 ашиглан Java программын нэгжийн тест бичиж, үр дүнг Maven-ээр шалгалаа. `GradeCalculator` классын хоёр методод нийт 14 тестийн метод хэрэгжүүлж, 27 тестийн гүйцэтгэл хийсэн. Хязгаарын утгуудыг тусгайлан шалгаснаар үнэлгээний ангиллын зааг дээр алдаа гарах эрсдэлийг туршсан. `assertThrows` ашиглан буруу оролтод зөв төрлийн алдаа үүсэж байгааг баталгаажуулсан. Хамгийн сонирхолтой нь `score >= 90` нөхцөлийг `score > 90` болгож өөрчлөхөд 90 оноог шалгадаг хоёр тест амжилтгүй болсон явдал юм. Энэ нь зөвхөн ердийн утгыг шалгах нь хангалтгүй бөгөөд хязгаарын утгын тест программын алдааг илрүүлэхэд чухал болохыг харууллаа. Эх кодыг сэргээсний дараа бүх 27 тест амжилттай ажилласан бөгөөд мутацийн туршилтаар тестүүдийн алдаа илрүүлэх чадварыг бодитоор баталгаажуулсан.
